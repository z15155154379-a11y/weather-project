# Weather Data Project

## 项目简介
本项目使用Python获取天气API数据，并进行数据分析与可视化。

## 功能
- 调用天气API获取数据
- 保存为CSV文件
- 使用pandas进行数据分析
- 使用matplotlib进行可视化

## 技术栈
- Python
- requests
- pandas
- matplotlib

## 使用方法
```bash
pip install -r requirements.txt
python weather_api.py
python analysis.py
